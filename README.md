# 🏠 House Price Prediction using Machine Learning

- This project uses Machine Learning to predict house prices based on input features


## 📌 Project Overview

- The model predicts house prices using numerical features
- Input features may include area, number of rooms, location, etc
- Output is the predicted price of the house
- This is a regression problem


## 📊 Dataset

- Dataset contains housing-related features
- Each row represents a house
- Features include:
  - Area
  - Bedrooms
  - Bathrooms
  - Location (if applicable)
- Target:
  - Price of the house

- Data Loading

- Model Training

- Prediction System
